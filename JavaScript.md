# JavaScript

## INTRODUCTION

### ¿Qué es JavaScript?

- Es el lenguaje de programación de la web.
- Fundamental para la interactividad.
- Ejecutado por el navegador.

### Funcionalidad Principal

- Manipula contenido HTML
- Cambia estilos CSS
- Controla eventos de usuario

### Datos Curiosos

JavaScript y Java son dos lenguajes completamente distintos en concepto y diseño.

Fue creado por Brendan Eich en 1995 y se convirtió en estándar ECMA en 1997.

ECMA-262 es el nombre oficial del estándar y ECMAScript es el nombre oficial del lenguaje.
